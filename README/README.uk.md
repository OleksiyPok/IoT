## Опис проєкту

Проєкт є прошивкою для ESP32, організованою у незалежні функціональні модулі.

З погляду користувача пристрій:

- підключається до WiFi та автоматично намагається відновити з'єднання після відключення;
- підключається до MQTT-брокера та автоматично керує MQTT-з'єднанням;
- підписується на топіки команд і даних сенсорів;
- отримує команди через MQTT та виконує підтримувані дії пристрою;
- отримує дані температури та освітленості через MQTT і використовує їх для індикації;
- забезпечує ручне керування освітленням кнопкою;
- підтримує тихий режим;
- підтримує тестування відключення та відновлення WiFi;
- керує світлодіодами відповідно до команд, робочих умов та аварійних станів;
- синхронізує системний час через NTP та надає доступ до UTC/локального часу;
- отримує інформацію про пристрій;
- за потреби виводить діагностичну інформацію в Serial Monitor у режимі `DEBUG_MODE`.

Індикація аварійних станів температури та освітленості керується конфігурацією під час компіляції:

- `DHT_TEMPERATURE_ALARM_MIN_CONFIG`
- `DHT_TEMPERATURE_ALARM_MAX_CONFIG`
- `LDR_LUX_THRESHOLD_LIGHT_LOW_CONFIG`

Стан пристрою представлений бітовими регістрами, що дозволяє одночасно зберігати декілька незалежних станів.

## Основний процес роботи

```text
Кнопки ─────────────────┐
                        ├──> Actions ──> System State ──> LED Indication
MQTT-команди ───────────┤
                        │
Дані сенсорів MQTT ─────┘

WiFi ──> MQTT Connection
NTP  ──> Системний час

DEBUG_MODE ──> Serial Monitor
```

## Зв'язок

MQTT використовується для двосторонньої взаємодії з пристроєм:

- команди отримуються з MQTT-топіка команд;
- дані сенсорів отримуються з MQTT-топіка сенсорів;
- отримані дані десеріалізуються та зберігаються для подальшої обробки;
- MQTT-з'єднання та підписки на топіки автоматично відновлюються після перепідключення.

## Кнопки та індикація

Підтримуються чотири кнопки:

- ручне керування командами;
- тихий режим;
- додатковий вхід кнопки;
- тестування відключення та відновлення WiFi.

Світлодіоди відображають активність команд, стани освітленості, температури, вологості та тихого режиму.

Для кнопок використовуються переривання та програмна обробка debounce.

## Час та інформація про пристрій

Прошивка ініціалізує системний час через NTP та підтримує:

- поточний UTC timestamp;
- структуру UTC-часу;
- локальний час із заданою часовою зоною;
- зміну часової зони під час роботи.

Також прошивка може отримувати ідентифікатор ESP32 WiFi STA та виводити інформацію про пристрій.

## Конфігурація

Робочі інтервали, параметри WiFi, параметри MQTT, призначення GPIO, відповідність кнопок і світлодіодів та аварійні пороги налаштовуються під час компіляції.

Прошивка побудована як модульна система з окремими модулями для кнопок, дій, команд, індикації, WiFi, MQTT, серіалізації, часу, інформації про пристрій, системного стану, пам'яті та моніторингу.
