## Опис проєкту

Проєкт є прошивкою для ESP32 для отримання даних і команд через MQTT та керування локальною LED-індикацією і кнопками.

Пристрій:

- підключається до WiFi та автоматично відновлює з'єднання після відключення;
- підключається до MQTT-брокера та підписується на топіки команд і даних сенсорів;
- отримує команди через MQTT;
- отримує дані температури та освітленості через MQTT;
- відображає окремі стани за допомогою світлодіодів;
- забезпечує керування ручною командою та тихим режимом кнопками;
- має кнопку для тестування відключення WiFi та автоматичного відновлення;
- може виводити діагностичну інформацію в Serial Monitor при увімкненому `DEBUG_MODE`.

## Основний процес роботи

```text
Кнопки ──> Actions ──> System State ──> LED Indication
                        ^
MQTT-команди ───────────┤
MQTT-дані сенсорів ─────┘

WiFi ──> MQTT
```

Для індикації температури та освітленості використовуються налаштовувані пороги:

- `DHT_TEMPERATURE_ALARM_MIN_CONFIG`
- `DHT_TEMPERATURE_ALARM_MAX_CONFIG`
- `LDR_LUX_THRESHOLD_LIGHT_LOW_CONFIG`

## MQTT

Прошивка працює з двома MQTT-топіками:

- `TOPIC_COMMANDS` — вхідні команди;
- `TOPIC_SENSORS` — вхідні дані температури та освітленості.

Повідомлення команд десеріалізуються за допомогою `deserializeCommand()`. Дані сенсорів десеріалізуються за допомогою `deserializeSensors()`.

## Кнопки та світлодіоди

Кнопки обробляються за допомогою переривань і програмного debounce (`BUTTON_DEBOUNCE_TIME_MS`).

Реалізовані елементи керування:

- `BUTTON_COMMAND_MASK` — ручна команда;
- `BUTTON_SILENT_MASK` — тихий режим;
- `BUTTON_WIFI_DISABLE_MASK` — тест відключення WiFi.

Стан світлодіодів представлений бітовими масками. У поточній реалізації використовується індикація команди, тихого режиму, низької освітленості та високої температури.

Ручна команда запускає коротку послідовність блимання LED (`MANUAL_BLINK_COUNT`, `MANUAL_BLINK_INTERVAL_MS`).

## Конфігурація

Параметри WiFi, MQTT, призначення GPIO, робочі інтервали, час debounce та пороги індикації налаштовуються під час компіляції.

Прошивка поділена на модулі для кнопок, дій, команд, індикації, WiFi, MQTT, десеріалізації, системного стану, часу, інформації про пристрій, пам'яті та моніторингу.
