# Завдання

## 1. Налаштувати середовище розробки

### Необхідно:

- Встановити **Wokwi** та **PlatformIO**
- Створити **GitHub-репозиторій курсу**

### Опис інструментів

**Wokwi** — браузерний симулятор мікроконтролерів: пишеш і тестуєш код без фізичного обладнання.

**PlatformIO** — професійне середовище розробки для embedded-проєктів.

**GitHub-репозиторій** стане твоїм портфоліо курсу — всі домашні завдання зберігатимуться там.

## 2. Ознайомитись із UART та USART communication

### Завдання:

Прочитати про принципи роботи послідовних інтерфейсів передачі даних.

### Теорія

**UART (Universal Asynchronous Receiver-Transmitter)** та **USART (Universal Synchronous/Asynchronous Receiver-Transmitter)** — два споріднених протоколи послідовної передачі даних.

Основна різниця:

- **UART** працює лише в асинхронному режимі.
- **USART** підтримує як асинхронний, так і синхронний режими роботи.

USART забезпечує більшу гнучкість у взаємодії з периферійними пристроями.

Саме через ці протоколи мікроконтролер:

- спілкується з комп'ютером через **Serial Monitor**;
- взаємодіє з модулями:
  - GPS;
  - Bluetooth;
  - GSM;
  - іншими периферійними пристроями.

Розуміння принципів роботи UART та USART знадобиться вже в цьому завданні.

## 3. Змінити колір світлодіода в симуляції

Перший крок у роботі з **GPIO (General Purpose Input/Output)** — навчитися керувати станом піна:

- вмикати;
- вимикати;
- змінювати параметри сигналу.

Це базова операція, на якій будується керування будь-якою периферією мікроконтролера.

---

## 4. Реалізувати сигнал SOS азбукою Морзе

### Вимоги:

- Крапка — **200 мс**
- Тире — **600 мс**
- Одночасно виводити символи `.` та `-` у **Serial Monitor**

### Опис

Завдання поєднує кілька навичок:

- керування GPIO у часі;
- реалізацію послідовності сигналів;
- базову роботу з UART через `Serial`.

Азбука Морзе — класичний приклад для відпрацювання роботи з часовими затримками (**timing**) у мікроконтролерах.
